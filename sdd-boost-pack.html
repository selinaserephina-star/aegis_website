// how skills work
  • Each skill is a .md file in .claude/skills/
  • Invoked as /skill-name in Claude Code chat
  • Claude reads the skill file, executes the encoded workflow
  • Skills chain tools: Glob, Grep, Bash, Edit — orchestrated
  • Works with any project — no config, no setup beyond install
  • Extend and override per-project: add your own in .claude/skills/

Skills are the operational layer of Skills-Driven Development (SDD). Instead of prompting from scratch each session, your team encodes proven patterns once — and invokes them.

// installation (2 steps)
# 1. Install globally (all projects)
mkdir -p ~/.claude/skills
cp -r sdd-boost-pack/skills/* ~/.claude/skills/

# 2. Verify in Claude Code
/commit ← git workflow, ready
/threat-model ← security audit, ready
/characterisation-test ← tests, ready

Or install per-project by placing skills in .claude/skills/ inside your repo. Per-project skills override global ones of the same name.
